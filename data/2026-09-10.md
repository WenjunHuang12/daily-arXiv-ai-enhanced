*Nathan White,Tian Zhang*

Main category: cs.DS

TL;DR: 该论文研究超高维 $\ell_\infty$ 度量下近似最近邻（ANN）问题，引入“子集嵌入”概念，给出空间 $O(n^2\log d)$、查询时间 $\tilde{O}(n^{1+1/c})$ 的数据结构，并证明匹配下界。


<details>
  <summary>Details</summary>
Motivation: 在超高维（$d \gg n$）情形下，希望查询时间不依赖于 $d$。已有工作（Herold 等, SoCG 2025）在 $\ell_1,\ell_2$ 上实现 $\tilde{O}(n)$ 查询时间，但在 $\ell_\infty$ 下查询时间高达 $\Omega(nd)$，效率低下，因此需要新的技术来处理 $\ell_\infty$ 的困难。

Method: 提出“子集嵌入”：通过仅选择部分维度来嵌入点（即忽略其余维求距离）。证明只计算 $n^{1+1/c}$ 个坐标即可将所有 $n$ 个点的两两距离保持到 $O(c)$ 因子，并给出相应下界。基于该嵌入构造 $\ell_\infty$ ANN 数据结构。进一步给出另一数据结构，将近似保证改进为 $O(c^{\log_2 3})\approx O(c^{1.58})$。

Result: 子集嵌入：用 $n^{1+1/c}$ 个坐标保持距离到 $O(c)$ 因子；下界表明存在点集使得任何近似 $c$ 的子集嵌入需 $n^{1+\Omega(1/c)}$ 个坐标。ANN 数据结构：空间 $O(n^2\log d)$、查询时间 $\tilde{O}(n^{1+1/c})$、近似 $O(c\log\log n)$；改进版本在相同空间与查询时间下近似 $O(c^{1.58})$，可实现 $O(1)$-近似且查询时间约为 $n^{1.01}$。

Conclusion: 该工作系统解决了超高维 $\ell_\infty$ 下 ANN 问题，通过子集嵌入在查询时间上达到近最优（仅略高于 $\Omega(n)$ 下界），并在近似与查询时间之间提供可控权衡。

Abstract: We study the approximate nearest neighbor problem under $\ell_\infty$ in the ultra-high dimensional setting where the dimension $d$ is significantly larger than the number of points $n$. Thus, we desire data structures with no dependence on $d$ in the query time. [Herold-Nanongkai-Spoerhase-Varma-Wu, SoCG 2025] introduce this problem and give data structures in $\ell_p$: for $p=1,2$, they give $(1+\varepsilon)$-approximation data structures with space $\tilde{O}(n\log d/\text{poly}(\varepsilon))$ and query time $\tilde{O}(n/\text{poly}(\varepsilon))$. Since any data structure must have query time $Ω(\min \{n,d\})$, this query time is nearly tight. However, their results are inefficient for $\ell_\infty$, with query time $Ω(nd)$.
  In order to handle the challenges of $\ell_\infty$, we introduce a notion of subset embeddings, which embed points by simply selecting a subset of dimensions. In particular, we show one may preserve all pairwise distances of an $n$ point dataset up to a factor of $O(c)$ by computing distances on only $n^{1+1/c}$ coordinates. We also show a matching lower bound: for any $c > 1$, there exists a set of $n$ points in $\mathbb{R}^{d}$ such that any subset embedding for the set with approximation $c$ must have at least $n^{1+Ω(1/c)}$ coordinates.
  Using our subset embeddings, we give data structures for approximate nearest neighbor in $\ell_\infty$ with space $O(n^2\log d)$, query time $\tilde{O}(n^{1+1/c})$, and approximation $O(c\log\log n)$ for any $c \geq 1$.
  Finally, we give another data structure for the approximate nearest neighbor under $\ell_\infty$ with the same space and query time as our subset embedding approach, but with approximation $O(c^{\log_2 3}) \approx O(c^{1.58})$. This allows us to achieve $O(1)$-approximation with query time e.g.~$n^{1.01}$
